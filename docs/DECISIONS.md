## 2026-11-16 · 주제 전환: 아수라장 예측 → 칼바람 패치 효과 측정

### 원래 계획
Riot API로 **칼바람 아수라장(ARAM: Mayhem, 큐 2400)** 경기를 수집해 챔피언·증강·맵 밸런스를 분석하고,
"내가 쓴 패치노트"를 만들어 다음 실제 패치노트와 비교해 적중률을 평가한다.

### 막힌 지점 1 — 아수라장 경기는 공개 API로 받을 수 없다
`src/feasibility/` 스크립트로 직접 확인했다.

| 확인 | 결과 |
|---|---|
| KR 랭크 시드 45명의 큐 2400 경기 목록 | 전원 0건 |
| 어젯밤까지 아수라장을 한 계정의 경기 목록 (필터 없이 100개) | 7월 아레나 1경기만 나옴 (계정 마지막 활동은 전날 밤) |
| 그 계정의 아수라장 경기를 ID로 직접 조회 | **403 Forbidden** |
| 같은 키로 아레나 경기 조회 / 없는 ID 조회 | 200 / 404 |

→ 경기는 존재하지만 접근이 막혀 있다(403 ≠ 404). 아수라장 경기는 목록에서도 빠진다.
외부 통계 사이트(증바람.com)도 "Riot이 큐 2400 매치를 공개 API로 제공하지 않아 모든 통계 사이트가 추정치를 쓴다"고 밝히고 있다.
관전(Spectator) API로는 진행 중인 경기를 볼 수 있지만, 승패와 증강(게임 중 선택)이 없다.

### 막힌 지점 2 — 다른 모드 데이터로 아수라장을 추정하기 어렵다
대안으로 "챔피언은 일반 칼바람(450), 증강은 아레나(1750) 데이터로 추정"하는 방법을 검토했다.
CommunityDragon 16.22 증강 메타데이터로 확인한 결과:

- 아수라장 증강 242개 중 아이콘이 아레나(Cherry) 폴더에 있는 것은 106개(약 44%). 나머지는 아수라장 전용 아트.
  이 106개도 현재 아레나 풀에 있다는 보장은 없다.
- `ARAM_` 접두사는 모드 구분 기준이 아니다. 아레나 목록에도 있고, 어느 목록에도 없는 것도 있다.
- 겹치는 증강도 수치 조정 가능성, 2인 팀 vs 5:5 차이, 제시된 선택지 구성 차이가 있다.
  데이터에는 고른 증강만 남고 선택지는 남지 않는다.

→ 가정이 겹겹이 쌓여, 결과가 맞든 틀리든 원인을 설명하기 어렵다.

### 막힌 지점 3 — 칼바람 전용 밸런스 변경은 드물다
일반 칼바람(450)으로 바꿔 "내 칼바람 패치노트 vs 실제"를 하려 했으나,
최근 패치노트에 칼바람 전용 변경이 없어 비교할 정답이 부족하다.

### 확인된 긍정적 사실 — 칼바람 데이터는 충분하다
- 랭크 시드 45명: 최근 14일 칼바람 5판 (랭크 유저는 칼바람을 거의 안 함)
- 칼바람 경기에서 만난 플레이어 37명: 1인당 14일 중앙값 48판, 고유 경기 1,802개
→ 시드를 칼바람 경기에서 확장하는 **스노볼 샘플링**이면 패치당 2~3만 경기 확보 가능. 병목은 API 리밋.

### 결정
**협곡 기준 패치(2주마다의 챔피언 너프/버프)가 칼바람 승률에 준 효과를 측정한다.**
- 패치 전후 + 변경되지 않은 챔피언을 대조군으로 하는 이중차분(DiD)으로 패치 효과를 추정한다.
- 결과로 "협곡 패치가 칼바람에서 과하게/약하게 작동한 챔피언" → 근거 붙은 칼바람 조정 제안을 만든다.
- 정답(실험 조건)은 매 패치노트의 챔피언 변경 목록이라 2주마다 생긴다.
- 아수라장은 데이터가 공개되면 같은 파이프라인으로 확장 가능한 부록 후보로 남긴다.

### 남은 확인 사항
- 지난 패치 경기를 `startTime`/`endTime`으로 얼마나 과거까지 소급 수집할 수 있는가
- 패치노트 챔피언 변경 목록을 어떤 형태로 구조화할 것인가
