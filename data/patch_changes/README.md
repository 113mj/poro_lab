# 패치 변경 목록

공식 패치노트를 읽고 직접 정리한 테이블입니다. 이중차분(DiD)의 처치군·대조군을 나누는 기준으로 씁니다.
패치노트 번호(`patch_label`, 예: 26.22)와 경기 데이터의 `gameVersion` 앞자리(`patch`, 예: 16.22)는 같은 패치입니다.

## 파일
- `champion_changes.csv`: 챔피언 단위 요약 (패치 × 챔피언 × 적용 범위당 1행)
- `change_lines.csv`: 변경 항목별 상세 (변경 전 → 후 수치). 챔피언과 아이템을 함께 기록

## 컬럼
| 컬럼 | 뜻 |
|---|---|
| `champion_name` | 경기 데이터 `participants.champion_name`과 같은 표기 |
| `scope` | `rift` 일반 밸런스(협곡 기준), `mayhem` 아수라장 전용, `classic` 클래식(옛 버전 챔피언) 섹션 |
| `applies_to_aram` | 일반 칼바람(450)에 적용되는지. `unknown`은 확인 필요 |
| `direction` | `buff` / `nerf` / `adjust` / `rework`. 패치노트에 태그가 없어 개발자 설명을 읽고 판단 |
| `n_lines` | 변경 항목 수 |

## 16.22 (패치노트 26.22, 2026-11-04 KST 게시)
출처: https://www.leagueoflegends.com/ko-kr/news/game-updates/league-of-legends-patch-26-22-notes/

- 일반 밸런스 14명: 상향 10, 하향 3(로크·쓰레쉬·야스오), 개편 1(멜)
- 아이템: 도란의 활 하향, 지배자의 피갑옷 조정 (교란 변수). 탐욕의 군화는 요약에만 언급되고 실제 변경 없음
- 룬 변경 없음, 칼바람 전용 피해 보정 변경 없음
- 아수라장 전용 변경(헤카림, 증강)은 일반 칼바람에 적용되지 않으므로 처치군에서 제외
- 클래식 섹션 11명은 옛 버전 챔피언 이벤트 관련으로 보이며, 일반 칼바람 적용 여부를 확인해야 함

## 아이템 변경 처리 (교란 변수)
아이템 변경은 그 아이템을 사는 챔피언에게 간접 버프·너프가 됩니다.
이런 챔피언이 대조군에 들어가면 대조군이 깨끗하지 않게 되어 DiD 추정이 틀어집니다.

| 아이템 (ID) | 변경 | 테스트 200경기 칼바람 구매 |
|---|---|---|
| 지배자의 피갑옷 (2501) | 공격력 30→40, 응징 +0~12% → +0~10% | 12명 (세트 8, 올라프·다리우스·자헨·일라오이 각 1) |
| 도란의 활 (1086) | 공격력 8→7 | 0명 → 칼바람 영향 미미 |
| 탐욕의 군화 (3008) | 실제 변경 없음 (패치노트 요약에만 언급) | 해당 없음 |

처리 방법:
1. 패치 전(16.21) 데이터에서 챔피언별 지배자의 피갑옷 구매율을 구한다.
2. 구매율이 높은 챔피언은 "아이템 노출군"으로 표시하고 대조군에서 빼거나 별도 그룹으로 추정한다.
3. 세트는 패치노트에서 "급상승하지 않도록 주의"했다고 밝힌 대상(응징 하향으로 상쇄)이라, 효과 방향 자체가 관심 대상이다.
